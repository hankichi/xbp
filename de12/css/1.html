Git & HTML

1. Gitについて

Git（ギット）は、ファイルの変更履歴を記録・追跡するための分散型バージョン管理システムのこと。

なぜGitが必要なのか？

  • 過去の状態にいつでも戻せる（簡単に修正前に戻すことができる）。
  • 「いつ・だれが・何を・なぜ変更したか」の記録が残る。
  • 複数人で同じファイルを同時に編集しても管理しやすい。

よく使うGitコマンド

  • git init：リポジトリ（保存庫）を新規作成する
  • git add .：変更したファイルをステージングエリア（提出準備）に追加する
  • git commit -m "メッセージ"：変更内容を記録（セーブ）する
  • git push origin main：ローカルの変更をGitHubなどのリモートリポジトリへアップロードする
疑問に思って調べたこと：GitとGitHubの違い
Gitは「ローカルのパソコン上で履歴を管理するツール（仕組み）」で、GitHubは「その履歴をインターネット上で共有・保存するためのWebサービス」である。

参考リンク：Git 公式ドキュメント

2. HTMLについて

HTML（HyperText Markup Language）は、Webページを制作するための言語のこと。

HTMLの基本構造

HTMLは「タグ」と呼ばれる記号（<tag>...</tag>）を使って、文章の見出しや段落、画像、リンクなどの要素を指定します。

代表的なタグ一覧

  • <h1> 〜 <h6>：見出しを設定する
  • <p>：段落（文章のかたまり）を作る
  • <a href="URL">：他のページへのリンクを貼る
  • <img src="画像パス" alt="説明">：画像を表示する
自分で調べて分かった点：セマンティックタグ（意味のあるタグ）の重要性
単に <div> で囲むだけでなく、<header> や <main>、<footer> を使うことで、検索エンジンや画面読み上げソフトに正しく構造が伝わる。
